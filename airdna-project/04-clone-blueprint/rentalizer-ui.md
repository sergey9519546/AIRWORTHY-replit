# Rentalizer UI Components

> What the interface looks like (from screenshots)

---

## Left Panel — Search & Filters
```
[Address/Location Input]
[Enable Dynamic Pricing Toggle]
Bedrooms: [Studio] [1-6]
Bathrooms: [1-6]
Guests: [1-16]
[Entire Place / Private Room]
[Property Type Dropdown]
Comp Set Quality: [Superhost] [Avg Rating 4.8+] [Superhost & 4.8+] [All]
Looking Back: [Time Period Dropdown]
```

## Center Panel — Map View
```
Mapbox map with listing pins
Color-coded by revenue: High (green) / Medium (yellow) / Low (red)
Shows comparable listings count (e.g., "215 comparable listings")
```

## Right Panel — Rentalizer Report
```
Property address
Annual Revenue Estimate
Monthly Revenue Breakdown (chart)
ADR (Average Daily Rate)
Occupancy Rate
Revenue Confidence Intervals
Comp Set Summary
Investment Metrics (Cap Rate, NOI)
```

## Comp Set View
```
[Map View] [List View]
Comp Set Strength: [Low] [Medium] [High]
[Edit Comps] button

List View columns:
- Listing title
- Bedrooms / Bathrooms
- ADR
- Revenue
- Occupancy
- Reviews
- Rating
- Days Available
```

## Revenue Charts
```
Monthly Revenue Projection (next 12 months)
- Each month shows revenue bar + confidence range
- Revenue range shading (min/max)

Historical Revenue (past 2 years)
- Shows how projection has changed over time
```

## Investment Calculator
```
Operating Expenses:
- Management fees
- Cleaning fees
- Insurance
- Taxes
- Maintenance
- Utilities
- Supplies

Purchase Price: [input]
Cap Rate: [calculated]
NOI: [calculated]
```
